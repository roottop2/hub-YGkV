# 电商智能问答系统 实现计划

> **执行说明：** 本计划按任务逐步实现，采用"每任务 = 可独立验证的交付物"的粒度。所有代码注释与文档使用中文；**不使用 git**（项目约定）。由 Claude 在本会话内逐任务执行。

**Goal:** 在 `意图识别/` 目录下构建一套可在 CPU 上跑通全流程的电商智能问答系统（模拟数据 → NER → 关系抽取 → 知识图谱 → BM25 检索 → Deepseek 生成 → Streamlit 界面），并配套设计文档与技术路线文档。

**Architecture:** 分层架构。离线：模拟数据生成 + 自动标注 → 训练 BiLSTM+CRF（NER）、R-BERT（关系抽取）、微调 BERT（意图）→ 知识融合 → 写入图存储抽象层（默认 networkx 内存图）。在线：Streamlit 界面 → NLU（意图 + 实体）→ 对话管理（槽位/反问）→ 检索（自实现 BM25 + 图查询）→ Deepseek 生成（失败降级模板）。

**Tech Stack:** Python 3.12（conda `python_ai`）、PyTorch 2.6 CPU、transformers 4.56、networkx、sklearn、jieba、openai、streamlit、python-dotenv。

## Global Constraints

- **中文**：所有注释、文档、日志文案用中文。
- **不用 git**：不执行任何 git 命令。
- **不装重型新依赖**：CRF 层自实现、BM25 自实现；不安装 rank_bm25 / torchcrf / seqeval。
- **BERT 预训练模型**：`bert-base-chinese`，首次运行需联网下载（约 400MB）；若 HuggingFace 无法访问，设置镜像 `HF_ENDPOINT=https://hf-mirror.com` 后重试。
- **Deepseek**：`openai` 库调用，`base_url=https://api.deepseek.com`，`model=deepseek-chat`，`api_key` 从 `.env` 读取 `DEEPSEEK_API_KEY`，**禁止写死**。
- **快速模式**：`config.QUICK_MODE=True` 默认开启（少数据、少 epoch），保证 CPU 演示能跑完。
- **Windows 中文路径**：所有路径经 `config.py` 统一管理，使用 `pathlib`；路径可能含中文（`D:\AI_学习\...`）。

```python
class CRF(nn.Module):
    def __init__(self, num_labels):
        super().__init__()
        self.num_labels = num_labels
        self.trans = nn.Parameter(torch.randn(num_labels, num_labels))

    def _log_sum_exp(self, x):
        m = x.max(dim=-1, keepdim=True).values
        return m + (x - m).exp().sum(dim=-1).log()

    def forward_alg(self, emissions, mask):
        seq_len, batch, _ = emissions.shape  # (T,B,L)
        score = emissions[0]  # (B,L)
        for t in range(1, seq_len):
            emit = emissions[t].unsqueeze(2)          # (B,L,1)
            trans = self.trans.unsqueeze(0)           # (1,L,L)
            nxt = score.unsqueeze(1) + trans + emit   # (B,L,L)
            score = torch.where(mask[t].unsqueeze(1), self._log_sum_exp(nxt), score)
        return self._log_sum_exp(score).sum(0)

    def score_path(self, emissions, tags, mask):
        seq_len, batch, _ = emissions.shape
        s = emissions[0, torch.arange(batch), tags[0]]
        for t in range(1, seq_len):
            s = s + self.trans[tags[t-1], tags[t]] + emissions[t, torch.arange(batch), tags[t]]
        return s

    def log_likelihood(self, emissions, tags, mask):
        return self.forward_alg(emissions, mask) - self.score_path(emissions, tags, mask)
```

**BM25 核心代码：**

```python
import math
from collections import Counter

class BM25Index:
    def __init__(self, docs, k1=1.5, b=0.75):
        self.k1, self.b = k1, b
        self.docs = docs
        self.doc_tokens = [tokenize(d) for d in docs]
        self.avgdl = sum(len(t) for t in self.doc_tokens) / max(len(docs), 1)
        df = Counter()
        for toks in self.doc_tokens:
            for w in set(toks):
                df[w] += 1
        self.df = df
        self.N = len(docs)

    def search(self, query, top_k=5):
        q_tokens = tokenize(query)
        scores = [0.0] * self.N
        for i, toks in enumerate(self.doc_tokens):
            tf = Counter(toks)
            dl = len(toks)
            s = 0.0
            for w in set(q_tokens):
                if w not in self.df or tf[w] == 0:
                    continue
                idf = math.log((self.N - self.df[w] + 0.5) / (self.df[w] + 0.5) + 1)
                s += idf * tf[w] * (self.k1 + 1) / (tf[w] + self.k1 * (1 - self.b + self.b * dl / self.avgdl))
            scores[i] = s
        ranked = sorted(range(self.N), key=lambda i: scores[i], reverse=True)
        return [(i, scores[i]) for i in ranked[:top_k] if scores[i] > 0]
```
